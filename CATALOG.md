# Command Skills Catalog

**604 self-taught command skills** — each an immense, standalone teaching
document generated by [`forge`](forge/forge.py) from the *real tools on the host*
(`pydoc` for Python, `--help`/`man` for CLI). Every skill passes `skillsmith lint`.

| Domain | Count | What it teaches |
|---|---:|---|
| `python` | 177 | Python standard-library modules (introspected via pydoc) |
| `bash` | 162 | Shell / CLI commands (introspected via --help / man) |
| `python-builtin` | 146 | Python built-in functions & types |
| `python-recipe` | 63 | Python idioms & recipes (comprehensions, generators, async, typing…) |
| `git` | 35 | Git subcommands |
| `pattern` | 21 | Shell command-structuring patterns (pipes, redirection, traps…) |
| **Total** | **604** | |

## Regenerate

```bash
python -m forge.forge          # forge the whole catalog
skillsmith lint skills --recursive   # validate every skill
```
