# Python: `pyexpat`

## Overview

Python wrapper for Expat parser.

## When to use

Reach for `pyexpat` when your task calls for Python wrapper for Expat parser. It ships with Python — no dependency to install, available on every interpreter.

## Import

```python
import pyexpat
```

## Key functions

- `pyexpat.ErrorString(code, /)`
- `pyexpat.ParserCreate(...)`

## Key classes

`ExpatError`, `XMLParserType`, `error`

## Constants / attributes

`EXPAT_VERSION`, `XML_PARAM_ENTITY_PARSING_ALWAYS`, `XML_PARAM_ENTITY_PARSING_NEVER`, `XML_PARAM_ENTITY_PARSING_UNLESS_STANDALONE`, `expat_CAPI`, `features`, `native_encoding`, `version_info`

## Structuring it in a program

Import once at the top of the module, then call into it where you need it. A
robust pattern wraps the call, handles the errors the module can raise, and
keeps the interface small:

```python
import pyexpat

def do_work(...):
    """Use pyexpat to accomplish one well-defined task."""
    result = pyexpat.ErrorString(...)
    return result
```

- Read the reference below for the exact signatures and exceptions.
- Prefer the highest-level function that does the job; drop to lower-level
  primitives only when you need the control.
- Keep `pyexpat` calls behind a small function so the rest of your code does not
  depend on its details.
