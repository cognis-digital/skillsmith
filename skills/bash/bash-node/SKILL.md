    # Command: `node`

    ## Overview

    Run JavaScript outside the browser with Node.js.

    ## When to use

    Use `node` when your task matches what it does best (see Overview). In a
    script, prefer it over hand-rolled logic — these tools are battle-tested,
    fast, and composable through pipes.

    ## Worked examples

    ```bash
node app.js
```
```bash
node -e 'console.log(1)'
```
```bash
node --version
```

    ## Structuring it in a program

    `node` is a building block in a shell pipeline. Compose it with `|`, guard on
    its **exit code**, and quote your variables:

    ```bash
    set -euo pipefail
    if node ... ; then
        echo "ok"
    else
        echo "node failed with exit $?" >&2
        exit 1
    fi
    ```

    - Chain with `|` to pass output to the next stage.
    - Check `$?` (or use `set -e`) — a non-zero exit means failure.
    - Quote `"$variables"` to survive spaces and globs.
